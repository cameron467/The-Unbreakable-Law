## Naming rule

- **The Unbreakable Method** = the project, repository and research methodology.
- **The Unbreakable Law** = the hypothesised deeper rule / consistency layer.

## Public navigation priority

The root README and `BEGIN_HERE.md` should link prominently to:

1. `00_NAMING_AND_SCOPE.md`
2. `Academic_Framework/Status/WHAT_IS_ACTUALLY_ESTABLISHED.md`
3. `Simplified_Framework/WHY_THIS_IS_NOT_A_THEORY_OF_EVERYTHING_YET.md`

## House style used in this package

- no emojis;
- dense technical-document layout;
- minimal horizontal rules;
- blockquotes only for warnings or core principles;
- GitHub-safe math only where actual mathematics is needed;
- ordinary Markdown for names, labels and workflows;
- explicit layer and status metadata;
- Project / Academic Framework / Simplified Framework kept separate;
- research notes clearly marked noncanonical;
- no claim that Parent #2, geometry, spacetime, GR or entanglement has been established;
- common-English TL;DR at the end of substantive pages.
